怎麼看票價

格內為含行李價（未設定託運時即票價）。✓ 已經 Google 驗證，「快取」仍待確認。點一格可看詳情與歷史。

★ ≤50% 半價▼ ≤70%≤85%≤100%>100% 比基準貴無資料

百分比是目前價格除以基準價；「只看好價」保留 ≤70% 的票價。★、▼ 讓不靠顏色也看得出好價。

關於提醒紀錄

低點比例＝保留紀錄中判為「低點」的筆數 ÷ 保留紀錄總數；價格變動不代表購票結果。紀錄保留至出發後 90 天。

票價行情

含行李來回均價，單位新台幣。過去是 LowFly 每天的紀錄；未來是各出發月份的 Travelpayouts 快取價，每天更新。

隱私與資料來源

本站不需登入、不收集個人資料，沒有追蹤或廣告程式。預算與離線資料只存在這支手機的瀏覽器。

航空公司標誌由 pics.avs.io 載入，對方會看到你的 IP 位址（不帶本站網址）。

票價來自 Travelpayouts（Aviasales）快取與 Google Flights，促銷消息來自 Google 新聞、PTT 與香港快運官網，僅供參考，以航空公司實際售價為準。

發現資安問題請到 GitHub 私下回報。

加入手機主畫面

Android：用 Chrome 開啟，點選單 →「安裝應用程式」。
